Eiger로 운영

Markforged 장비는 Eiger를 중심으로 파일 준비, 소재/섬유 배치, 장비 관리, 조직 보안을 연결합니다. 구매 검토자는 첫 화면에서 실제 운영 흐름과 필요한 계정 범위를 확인할 수 있습니다.

Modules

Digital Forge 구성 모듈

Eiger (슬라이서 · 관리)

CAD → 파트 슬라이싱 · 프린트 큐 · 소재 선택 · 파라미터 관리. 클라우드 · 오프라인 모두 대응.

  • 웹 브라우저 기반 (설치 불필요)
  • Eiger for Enterprise 옵션
  • Educator 라이선스 (교육용)

Simulation

프린트 전에 파트 강도 · 하중 · 응력 시뮬레이션. 섬유 라우팅 최적화 · 재료 절감.

  • 하중 방향 · 지지점 정의
  • 안전 계수(FoS) 계산
  • 섬유 개수 · 방향 자동 추천

Inspection

공정 중 실시간 파트 검사. FX10은 본체 내장, X7은 Blacksmith 옵션.

  • 레이저 마이크로미터 (X7)
  • 비전 캘리브레이션 (FX10)
  • 층별 편차 로그

Management & Integration

여러 대의 프린터를 중앙 관리. ERP · MES · PLM 통합 · 조직 롤 관리.

  • Fleet Dashboard (프린터 상태 · 큐)
  • 사용자 · 조직 · 프로젝트 롤
  • REST API

Digital Source

디지털 부품 카탈로그. 필요 부품을 즉시 검색 · 라이선스 · 프린팅.

  • OEM 승인 파트
  • 디지털 재고 · 원격 사용

보안 (Security)

엔터프라이즈 · 방위 대응. FIPS · SAML SSO · 2FA · 감사 로그 · IP 보호.

  • FIPS 140-2 준수
  • SAML SSO · Azure AD · Okta
  • 2단계 인증 · Audit Log
Eiger Subscription

Eiger 서브스크립션 플랜

규모 · 요구에 맞는 3가지 플랜. Cloud (표준) · Enterprise (조직 관리 · SSO) · Educator (교육 기관 할인).

플랜 비교 개요
Cloud웹 브라우저 슬라이서 · 개인 · 소규모 팀
Enterprise조직 관리 · SSO · Fleet · Audit · Priority Support
Educator교육 기관 특별 라이선스 · 강의 실험실

플랜 선택 상담

도입 규모 · 부서 · 프린터 대수 · 보안 요구에 맞는 최적 플랜을 국내에서 함께 검토합니다.

Workflow

Eiger 프린트 워크플로우

1

CAD 업로드

STL/STEP 파일을 Eiger 웹에 업로드. 자동 방향 · 자동 서포트.

2

소재 · 섬유 선택

Onyx · Onyx FR · Nylon White FS · CFR 카본/유리섬유/케블라 등.

3

파라미터 조정

Layer · Infill · CFR 개수 · Wall · Roof/Floor · 온도 프로파일.

4

프린트 · 모니터링

큐 전송 → 프린터 자동 시작 · 챔버 카메라 · 프로세스 로그 실시간.
